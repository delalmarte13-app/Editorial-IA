# CANON — VERDAD OFICIAL DEL PROYECTO

Este documento contiene la información que ninguna fase del proyecto puede contradecir sin registrar primero una decisión.

## Personajes
Para cada personaje registrar: nombre canónico, edad aproximada, apariencia, personalidad, relaciones, objetivos, rasgos visuales y evolución.

## Mundo
Registrar lugares, reglas del mundo, época, arquitectura, clima, objetos recurrentes y elementos culturales.

## Historia
Registrar los acontecimientos que han ocurrido y que no pueden contradecirse en escenas posteriores.

## Visual
Registrar estilo artístico, proporciones, paleta, vestuario, iluminación y referencias visuales.

## Regla de conflicto
Si una nueva propuesta contradice el CANON, detener la ejecución y resolver primero la contradicción mediante `DECISIONES.md`.
