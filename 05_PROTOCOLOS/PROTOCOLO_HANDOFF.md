# PROTOCOLO DE HANDOFF

Toda transferencia entre herramientas o agentes debe incluir:

## OBJECTIVE
Objetivo concreto.

## MINIMUM CONTEXT
Solo el contexto indispensable para ejecutar correctamente.

## SOURCES
Archivos, versiones o referencias que deben consultarse.

## INSTRUCTIONS
Acciones específicas y ordenadas.

## CONSTRAINTS
Restricciones, CANON y elementos que no deben modificarse.

## SUCCESS CRITERIA
Cómo se verificará que el resultado es correcto.

## OUTPUT
Formato exacto de entrega.

## DO NOT DO
Errores, cambios o supuestos prohibidos.

## RETURN
El agente devuelve: resultado, decisiones tomadas, dudas, problemas detectados y archivos creados/modificados.
